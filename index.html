Wall Is You

Jeu de puzzle où le joueur incarne un donjon bienveillant devant guider un aventurier à travers des salles pivotables pour vaincre des dragons.

Type
SAÉ
Équipe
Binôme
Durée
5 mois
Année
2025-2026
Python 3
Contexte

SAÉ du module Initiation au développement. Les rôles sont inversés : le joueur est le donjon, l'aventurier est automatique. Projet en 3 rendus de complexité croissante.

Fonctionnalités
  • Moteur de jeu : grille de salles représentées par tuples de booléens
  • Rotation des salles : pivot de 90° au clic
  • Pathfinding : calcul automatique de l'intention de l'aventurier (BFS)
  • Lecture de fichiers de donjons avec caractères spéciaux
  • Variantes : trésors, sauvegarde, déplacement des dragons
Ma contribution
  • Conception du moteur de jeu
  • Algorithme de pathfinding
  • Interface graphique avec fltk
  • Lecture et parsing des fichiers de donjons
Compétences développées
  • Algorithmique avancée : parcours de graphes, BFS
  • Programmation Python et interface graphique fltk
  • Travail collaboratif avec Git / GitHub
